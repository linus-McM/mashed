# uiadapter-01: Rewrite `prompt.md` to restore the role contract and tighten field discipline

**Status:** ready
**Domain:** backend
**Size:** S
**Depends On:** none
**Priority:** P0-critical

## Story

As a UIAdapter maintainer, I want the embedded system prompt (`internal/uiadapter/prompt.md`) to carry a complete role contract, explicit envelope-omission rules, camelCase field discipline, slugification guidance, and CLI-chrome-ignore guardrails, so that `gemma3:4b` emits well-shaped UIAST v1 JSON consistently and stops degrading to fallback on cosmetic differences.

## Description

Rewrite `internal/uiadapter/prompt.md` only. No Go code changes in this story. The current prompt's line 3 terminates mid-sentence ("…only publish the output generated by "), leaving the role contract incomplete. The rewrite restores the intended contract, tightens the field-name rules so `DisallowUnknownFields()` inside `WidgetNode.UnmarshalJSON` (schema.go:83–93) no longer hard-rejects near-misses, and adds the slugification rule targeted by `TestPrompt_Golden_Brainstorming` / `_Elicitation`. Prompt version stays `"v1"` (restoration — not a semantic change). Byte budget `[1500, 6000]` as enforced by existing tests.

### Scope summary
- Complete the role contract on line 3 so the "never invent content" directive reads as a full sentence.
- Envelope section explicitly lists `generated_by`, `generated_at`, `diagnostics` under **omit** (the adapter stamps them in `adapter.go:136–148`).
- New "Field-name discipline" block enumerating `maxLength`, `multiline`, `copyable`, `repoRootRelative` camelCase forms and surfacing the STRICT widget-decoding warning.
- New slugification rule for `options[*].value`: lowercase hyphen-separated slug of the source term; literal numerals `"1"`..`"5"` when the source uses numbered lists.
- Safety section adds an explicit CLI-chrome-ignore rule (ANSI, tmux status, box glyphs, spinner frames).
- Examples rewritten to match `testdata/prompts/*-raw.txt` fixture shapes without leaking specific option slugs beyond the slugification rule.

### Non-goals
- No changes to `prompt.go` (`promptVersion` stays `"v1"`).
- No changes to `adapter.go`, `client.go`, `schema.go`, `validator.go`, or tests.
- No regeneration of `testdata/prompts/*-response.json` golden fixtures in this story.

## Developer Notes

### Files to modify
- `internal/uiadapter/prompt.md` — full rewrite. The rewritten content is provided alongside the plan as `outputs/prompt.md` (reference artifact — see plan §1 Story 1).
- Nothing else.

### Byte budget and version
- `prompt_test.go:18–20` enforces `1500 ≤ len(prompt) ≤ 6000`. Target ~5.0 KiB.
- `promptVersion` constant in `prompt.go` stays `"v1"`. Do NOT bump — this is a restoration of intent, not a semantic change (see plan §3 "Prompt-version bump rule").

### Required sections (section headings must be present)
- **Role** — completed role contract including "never invent content the source turn did not already contain. Publish only content that appears in the source turn."
- **Schema** — UIAST envelope + node types + widget union, with camelCase field discipline block.
- **Examples** — at least two, aligned with `testdata/prompts/*-raw.txt` shapes.
- **Output contract** — explicit omit list (`generated_by`, `generated_at`, `diagnostics`) and slugification rule.
- **Safety** — CLI-chrome-ignore rule and "do not copy ANSI / box glyphs / spinner frames" guardrail.

### Slugification rule (exact text the prompt must teach)
- Option `value` is the lowercase hyphen-separated slug of the source term (e.g. source `"Brainwriting"` → `value: "brainwriting"`).
- When the source is a numbered list (`1. Foo`, `2. Bar`), `value` is the literal numeral `"1"`, `"2"`, …, `"5"`.
- Targets assertions in `TestPrompt_Golden_Brainstorming` (expects `"brainwriting"`) and `TestPrompt_Golden_Elicitation` (expects numeric values).

### Envelope omit discipline
- Prompt must state that the model emits only `version`, `title`, `nodes`, `schema` (and any UIAST v1 payload leaves). `generated_by`, `generated_at`, `diagnostics` are adapter-stamped and must NOT be produced.

### Risks / gotchas
- If the live Ollama model drifts on option slugs after this rewrite, the correct action is to rebaseline the `testdata/prompts/*-response.json` fixtures — do NOT regress the prompt. Flag any rebaseline in the PR description (plan §1 Story 1 risk note).
- Keep examples abstract enough that they don't leak specific option slugs beyond the slugification rule itself; otherwise the golden tests become brittle to prompt edits.
- `TestSystemPrompt_ContainsAllSections` checks for the section headings listed above — do not rename them.
- `TestAdapter_SendsSystemPromptInRequest` verifies the embedded prompt appears in `messages[0].content`; any truncation at embed time will fail it.

### Reference files
- `internal/uiadapter/prompt.md` — current (broken) prompt.
- `internal/uiadapter/prompt.go` — `promptVersion` constant; do not edit.
- `internal/uiadapter/prompt_test.go` — golden and version assertions.
- `internal/uiadapter/testdata/prompts/*-raw.txt` + `*-response.json` — golden fixtures this prompt must still produce aligned output against.
- `internal/uiadapter/schema.go` — `WidgetNode.UnmarshalJSON` `DisallowUnknownFields()` at lines 83–93.
- `internal/uiadapter/adapter.go` lines 136–148 — envelope stamping the prompt must defer to.
- `docs/plans/IMPLEMENTATION_PLAN.md` §1 Story 1.
