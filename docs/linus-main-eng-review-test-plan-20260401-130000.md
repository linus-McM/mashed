# Test Plan
Generated by /plan-eng-review on 2026-04-01
Branch: main
Repo: mashed

## Affected Pages/Routes
- Notification Feed (home view) — verify events appear, sorted by priority, clickable
- Agent Detail (drill-down) — verify terminal loads, scoped files shown, worktree info displayed

## Key Interactions to Verify
- Agent event appears in feed within 5 seconds of Claude session starting
- Click notification → correct agent terminal loads in under 1 second
- Terminal keystroke → reaches agent pty and echo appears
- Scoped file list shows only files the selected agent modified
- Worktree panel appears when agent has a worktree

## Edge Cases
- Agent exits in < 5 seconds (short-lived) — should still appear via fsnotify
- Malformed JSONL line — should skip gracefully, not crash
- tmux pane disappears mid-session — should show "pane lost" state
- WebSocket drops — should show reconnecting overlay
- 10+ simultaneous agents — should all appear, no lag

## Critical Paths
- Process scan → JSONL parse → notification engine → Wails event → frontend render
- Notification click → WebSocket connect → pty attach → xterm.js render
- Worktree detection → diff stat → scoped file list render
